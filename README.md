# skills

私有 skill 仓库，收录以下 WorkBuddy skill（每个子目录含独立 SKILL.md / README.md）：

1. **article_formate** — 公众号文章排版 skill 整改后的工程目录（由 `wechat-article-format` 拆分重构而来），**已正式取代 `wechat-article-format`（旧版已废弃、不再维护）**。
2. **renshe-writer** — 本技能是写作人设工坊，三大能力：①从样稿提炼可复用的「风格层+骨架层」人设并存库；②管理已存人设（列出/查看/编辑/补提/重命名/删除/导出）；③调用某套人设产出内容（图文文章/双版公众号+小红书/图片贴图文案+小红书 caption）。用自然语言描述意图即可触发，无需记命令。不覆盖纯标题生成（xhs-title-factory/meta-topic-plan）、纯出图渲染、OCR 预处理。可选 Web 管理端端口 8003。
3. **begin-end** — 本技能专项优化文章的「开头」与「结尾」两段（不碰中段、不写标题、不出图）。覆盖母婴/娱乐/情感/人生哲学励志/女性觉醒/财经六域，按领域路由到对应打法手册，提供可直接套用的开头钩子与结尾模板、反套路原则与自检清单；母婴域强制套用福宝妈妈 IP 身份映射。当用户要求优化开头、改结尾、打磨开头结尾、做爆款开头/治愈结尾/金句结尾时触发。
4. **xhs-title-factory** — 本技能是小红书爆款标题工厂（路由版）。收到标题优化请求后先判定内容领域——母婴/育儿/亲子、娱乐/明星/影视综艺/八卦、情感/婚姻/恋爱/关系/情绪、财经/理财/投资/股市/楼市/通胀/攒钱、个人成长/人生哲理/认知/内耗/觉醒、或其他生活通用——再路由到该领域专属标题逻辑（各自独立人设与底层心法，绝不用一套通用模板硬套）。触发词：帮我起小红书标题、优化这个合题标题、给我的 note 改爆款标题、来 3 种风格做 A/B 测试。每个标题需命中至少 2 个所属领域公式/筛子。
5. **meta-style-extract** — 本技能是公共元 skill（可组装构件），负责从网页源码中抽取结构化公众号排版样式配置。本身不含任何在线获取能力——只消费由 meta-web-fetch 取得的网页源码字符串。任何需要从参考文章反推排版风格（颜色/标题/引用/强调等）的上层 skill 都应委托本技能，避免各自实现。
6. **meta-web-fetch** — 本技能是公共元 skill（基础设施层），负责网页/本地 HTML 抓取与正文提取，并支持把访问到的网页（HTML+图片）下载到本地目录，产出自包含、可离线预览的产物。任何需要取网页源码或正文的上层 skill 都应委托本技能，不再各自实现抓取。
