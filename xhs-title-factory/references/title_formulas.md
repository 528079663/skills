## 母婴

**6 大爆款心法（完整公式/精髓/✅案例/❌对比见 `references/muying.md`；命中 2 个以上达标，3–4 个有爆款潜质）**：

| 心法 | 一句话钩子 | 爆款示范 |
| :--- | :--- | :--- |
| 一·痛点直击 | 具体痛苦场景 + 否定/转折 + 解决暗示 | 抱着娃走到凌晨三点？别硬扛，肠胀气 5 个真·有效安抚法 |
| 二·数字清单 | 数字 + 问题/技巧 + 结果承诺（**禁纯月龄/月份标记单独当钩子**；**禁模糊数字噱头：抛数字须有落点**，见 `references/muying.md` §4.0「月份假数字/数字无落点」） | 0-1岁只需买这 4 样玩具，其他都是乱花钱 |
| 三·对比反常识 | 常见错误 + 别/错/居然 + 正确观点（**禁裸 `A≠B`、禁"搞混"钩子、禁"X在升级"鸡汤 reframe**，见 `references/muying.md` §4.0 黑名单） | 把屎把尿不是"为孩子好"，是跟括约肌有仇 |
| 四·情感扎心 | 身份标签/时刻 + 戏剧化真实情绪 | 当妈后，我重新理解了什么叫"困"：站着洗澡都能睡着 |
| 五·捷径救命 | 一个动作/一句话 + 搞定 + 棘手问题 | 一张图看懂宝宝大便！别再去网上搜吓人的图了 |
| 六·悬念后悔 | 后悔没早知道/差点就… + 后果 + 正确做法 | 后悔！宝宝牙齿烂光才明白：出第一颗牙就该做这件事 |

> **⚠️ 母婴标题·搜索/工具子类型（补丁）**  
> 当内容为「对照表/发育标准/疫苗清单/辅食日历/囤货清单」时，**强制切到搜索逻辑**，不再死磕上方 6 心法中的痛点/对比/后悔。
>
> **搜索型公式模板：**
> - `[月龄] + [发育对照表/奶量标准/疫苗时间] + [一篇看懂/直接对] + [✅建议打印/🔥收藏]`
> - **案例**：`1月龄宝宝发育对照表（身高/体重/奶量）✅存图直接对`
> - **命中的是**：`〔搜索·长尾词覆盖〕+〔二·数字清单〕`（若无数字，则只标 `〔搜索·长尾词覆盖〕`）。
> - 此类标题**不强制**标注命中了〔一·痛点直击〕/〔三·对比反常识〕/〔六·悬念后悔〕，验收时只看**长尾词数量（≥3 个）** 和**收藏指令**。

**❗母婴硬约束（生成前必查，违反即作废重生成）**：① 对比反常识必须点出〔常见错误做法〕+〔正确观点〕，裸 `A≠B`、仅说"搞混"无后果无收益一律不通过（反模式黑名单见 `references/muying.md` §4.0）；② 输出必须是「主+副」齐全，缺副标题不通过；③ 〔痛点直击/对比反常识/悬念后悔/情感扎心〕至少命中 1 个**真·强钩**（伪对比/伪痛点/安慰皮不计），0 真·强钩不通过（详见 `references/muying.md` §二硬门禁"真·强钩判定"）；④ 封面主标题（mainTitle）≤20 字（含标点/数字/空格/Latin 各计 1 字），超限重生成（详见 `references/muying.md` §五「封面主标题字数硬约束」+ §二硬门禁「主标题超长」）。

**副标题原则**：去掉「指南/手册/攻略/注意事项」空泛词，换成**具体动作 + 用户可感知的收益**，且**须与主标题抛出的数字/承诺承接**（❌ 新手爸妈对照看 / 仅给时长 → ✅ 3条判断标准对照完安心了 / 4件事逐个做娃抬头稳了）。

**封面标题换行约定**：封面主标题断点仅限 ？/！ + 空格 + `／`（详见 `references/muying.md` §五「封面标题换行约定」）；**全角冒号 `：`/半角`:`/破折号`—`/顿号`、` 等「标签式」标点禁止用于主标题**（引擎会转空格致两从句黏连、且像标签不像钩子）；作者撰写主标题时应多用 ？/！或空格分隔，主动预留自然断点，便于封面整齐换行。

**母婴自查清单**（写完逐条打钩，少于 3 个钩重写）：有痛 / 有数 / 有情 / 有利 / 有密 / 副标题有动作。**红线**：不夸大不恐吓、标题是承诺正文必须兑现；严禁标题党与内容不符、严禁制造不必要的新焦虑（如《三岁前不会这个，智力发育会落后》禁用）。**交付前另须过 `references/muying.md` §二「❗硬门禁」**：副标题无效 / 0 真·强钩 / 仅对比外壳 / 数字灌水 / 数字无落点 / 不流畅（生硬拼接） / 主标题超长（>20字） 任一命中即作废重生成。（⚠️ 但「搜索/工具型」干货按 `references/muying.md` §七 执行，豁免「0 真·强钩」「仅对比外壳」，改验「长尾词 ≥3 个 + 强收藏指令」。）

## 娱乐

**底层 4 心理驱动**（标题至少要打中一个）：信息缺口 / 情绪共鸣 / 社交货币 / 简单围观。

**7 种爆款公式（命中 1 个即达标，2 个以上有爆款潜质）**：

| 编号 | 公式 | 模板 | 爆款示范 |
| :--- | :--- | :--- | :--- |
| ① | 悬念反转 | 谁 + 竟然做了 X + 结果意外 | 某某片场突然崩溃大哭，导演一句话，全场都安静了 |
| ② | 情绪站队 | 全网骂/捧 XX，但我偏要说…（反主流、逻辑自洽） | 全网都在夸她"清醒大女主"，抱歉，我只看到了鸡贼 |
| ③ | 数字盘点 | 数字 + 总结名词 + 半遮半掩细节（奇数/非整数，最劲爆放最后） | 内娱最该"消失"的 4 位男明星，第一名居然是他 |
| ④ | 对比冲突 | 两个反差极大的事物/状态放一起 | 她曾是顶流女王，如今在小县城卖茶叶，一条视频点赞 3 万 |
| ⑤ | 强代入共鸣 | 你经历过的感受 + 娱乐事件作出口 | 看了某某的离婚声明，我终于懂了什么叫"体面分手" |
| ⑥ | 金句提炼 | 把文章最扎心的一句话直接做标题 | 娱乐圈不缺漂亮的脸蛋，缺的是敢摔饭碗的骨头 |
| ⑦ | 信息增量 | 熟悉的旧人旧事 + 完全不知道的新细节 | 重看 20 年前的《还珠格格》，才发现皇后才是三观最正的人 |

**体裁发力点**：
- 吃瓜爆料 → 强调时效/细节/独家感，善用【】标「独家/深度扒/时间线整理」。
- 影视综艺评 → 要么极专业要么极情绪。
- 人物深度稿 → 聚焦「人味儿」+ 命运感。
- 搞笑猎奇盘点 → 极致画面感 + 无法想象的形容。

**精修阶梯（标题手术室）**：原始 → 加数字共鸣 → 加悬念情绪 → 加对比身份，每一句都在加码。

**娱乐避坑（踩任一条必须重写）**：① 杜绝虚假夸大（「去世」类谣传是死穴）② 远离低俗/价值观踩雷 ③ 不做纯标题党（标题是承诺，正文必须兑现）④ 规避侵权（慎素人照、不编对话、引源标注）。

**娱乐多风格 A/B**：犀利反主流型 / 共情嘴替型 / 吃瓜快讯型。

## 情感

**4 种核心钩子（标题至少要打中一个）**：痛点共鸣 / 故事悬念 / 观点反常识 / 身份标签。

**5 种爆款公式（命中 1 个即达标，2 个以上有爆款潜质）**：

| 编号 | 公式 | 模板 | 爆款示范 |
| :--- | :--- | :--- | :--- |
| ① | 痛点场景化 | 谁 + 在什么具体场景 + 有什么扎心感受 | 远嫁五年，除夕夜为去谁家大吵一架后，我才读懂了婚姻 |
| ② | 关系-对比反转 | 看似很好的关系 + 意想不到的结局/真相 | 朋友圈那个宠妻狂魔，出轨了 |
| ③ | 我/你-结论 | 第一人称「我」+ 教训 + 给「你」的终极建议 | 用了三年我才明白，好的关系都需要"间歇性冷漠" |
| ④ | 提问-颠覆认知 | 为什么 + 常见情感观 + 我反对的理由 | 为什么越懂事的人，越不被珍惜？ |
| ⑤ | 瞬间-顿悟 | 在一个什么瞬间 + 突然想通一个道理 | 在产房外听到婆婆一句话，我决定不离婚了 |

**精修阶梯（层层加码）**：讲道理（60）→ 加场景痛点（75）→ 加反转和代入（85）→ 提炼金句一击即中（95）。每一版都往「扎心度 + 代入感」再捅一刀。

**情感底线（踩任一条必须重写）**：① 不贩卖焦虑制造恐慌（如诱导猜忌「不看手机心里有鬼」）② 不物化关系宣扬对立（警惕把关系物质化、煽动性别对立）③ 不窥探隐私拿悲剧引流（不用「跳楼/自杀」等极端词）④ 标题撕开伤口，正文必须抚慰或解答（提供温暖/理性出口）。

**情感多风格 A/B**：扎心共鸣型 / 故事悬念型 / 反常识犀利型 / 身份标签型。

## 财经

**心理七寸（标题至少敲中一个）**：财富焦虑与损失厌恶 / 信息差红利 / 阶层滑落恐惧 / 简单归因与实用主义。

**7 种爆款公式（命中 1 个即达标，2 个以上有爆款潜质）**：

| 编号 | 公式 | 模板 | 爆款示范 |
| :--- | :--- | :--- | :--- |
| ① | 反常识+财富结果 | 常见财富观念 + 颠覆结论 + 真实差距 | 靠死工资存钱的人，将输掉下半场 |
| ② | 数字对比+身份代入 | 同起点/金额 + 不同选择 + X 年后天壤之别 | 同样月薪 8000，一个买了包一个买了基金，10 年后两人都愣住了 |
| ③ | 紧急预警+避坑指南 | 危险信号词 + 涉及人群 + 保护性动作 | 今年春天，劝你捂紧口袋，别碰这四种"理财" |
| ④ | 身份标签+痛点揭示 | 圈定一类人 + 共同财务困境/错误 | 30 岁还没存款的人，都败在了这两个习惯上 |
| ⑤ | 故事冲突+财富教训 | 具体财富跌宕故事 + 一句灵魂总结 | 那个借钱加杠杆的朋友，昨天退群了，留下一句"别走我的路" |
| ⑥ | 趋势信号+行动指南 | 被忽视的信号 + 暗示走向 + 你的准备 | 央行这次表态不寻常，普通人守好钱袋子的三个信号 |
| ⑦ | 金句提炼+认知颠覆 | 违背直觉却异常真实的一句话 | 通货膨胀是穷人的绞肉机，却是富人的提款机 |

**体裁发力点**：
- 突发快讯/政策解读 → 强调速度、影响面、与你直接关联（关键词：刚刚、突发、速看、与你有关）。
- 深度商业分析/人物 → 提炼最戏剧性的兴衰转折，聚焦「为什么没做错却输了」。
- 理财科普/投资教育 → 直击小白痛点，给马上能用的清单。
- 楼市/股市评论 → 用具象细节破除迷茫，给清晰观点；预测留余地，不煽动极端情绪。

**精修阶梯（层层加码）**：正确废话（50）→ 加身份场景（70）→ 加对比紧迫（85）→ 反常识结论+情绪（95）。把「正确的废话」变「扎心的实话」。

**财经生死线（踩任一条轻则限流，重则封号甚至担责，必须重写）**：① 绝不承诺收益、不做「神仙预测」（「必涨停」「稳赚不赔」禁区）② 不制造不传播金融谣言（无「内幕消息」）③ 避免社会恐慌（不用「崩盘/暴跌/大洗牌」夸大，银行保险措辞审慎）④ 客观中立不为利益站台 ⑤ 标题「危言」正文必须给理性「解药」。

**财经多风格 A/B**：反常识扎心型 / 预警避坑型 / 趋势解读型。

## 成长/认知

**4 个钩子（标题至少占一个）**：戳痛点（说清他忍受却说不清的烦恼）/ 给希望（看到「我也能改变」的路径）/ 造共鸣（「你懂我」）/ 破认知（反常识击碎旧想法）。
- 子领域配比：个人成长 痛点40%+希望40%+共鸣20%；人生哲理 共鸣50%+破认知30%+希望20%；认知升级 破认知60%+痛点30%+希望10%。

**5 个黄金公式（命中 1 个即达标，2 个以上有爆款潜质）**：

| 编号 | 公式 | 模板 | 爆款示范 |
| :--- | :--- | :--- | :--- |
| ① | 痛点场景+否定/反常识 | 你以为的 A 其实是 B / 别再 C 了真正有效的是 D | 天天打卡早起，正在慢慢毁掉你 |
| ② | 强限定词+深度洞察 | 一个/真正/所有/永远…的顶级思维/底层逻辑 | 真正能成事的人，都掌握了这 1 个"滞后满足"模型 |
| ③ | 身份标签+强烈态度 | 致 XX 的人 / XX 性格的人请一定要… | 给自卑敏感的你：请放肆地活出攻击性 |
| ④ | 数字具象化+可操作利益 | 数字 + 让你/帮你/戒掉 + 具体结果 | 让你脱胎换骨的 12 个微习惯，坚持 30 天效果惊人 |
| ⑤ | 旧词新解/概念冲击 | 一个你不知道的 XX / 这才是真正的 XX | 所谓成熟，就是理解"一切都是交易" |

**高能关键词弹药库**（过程词反人性、结果词高诱惑）：动作（戒掉/停止/重构/唤醒/穿透）；身份（狠人/觉醒者/高敏感者/长期主义者）；境界（通透/开窍/内核稳定/屏蔽力/配得感/钝感力）；认知动词（看透/顿悟/破局/重塑/思维越狱）；哲理词（本质/底色/底层逻辑/闭环）。

**平台微调**：本 skill 主战场是小红书——标题短而直接、强人称「我」、像闺蜜分享、利搜索（例：相信我，这 5 个认知习惯让我一年顶十年🔥）；若用户指明公众号/知乎/抖音再按对应策略调。

**成长/认知避坑（踩任一条必须重写）**：① 不说教要唤醒（用「我希望」替「你应该」）② 不空泛要具体（宏大问题压缩进极具体场景/动作）③ 不贩卖焦虑过度、要给希望出口（刺痛—安抚—给予工具闭环）。

**成长/认知多风格 A/B**：扎心共鸣型 / 反常识破认知型 / 数字清单型。
