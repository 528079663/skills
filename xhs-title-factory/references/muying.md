# 母婴爆款标题完整方法论（muying）

本文件是 `xhs-title-factory` 路由到 **母婴** 领域时的完整实现参考。
SKILL.md 中的母婴章节是结构化摘要；本文件是「可直接照做的全量指南」，改造母婴标题前先读本节对齐心法与颗粒度。

> **母婴标题的本质**：母婴类文章的标题，是决定妈妈们划不划开的关键一秒。她们可能正抱着孩子喂奶、或在深夜焦虑地搜索。一个好标题，要能瞬间击中两样东西：**她的焦虑**和**她的期待**——既让她觉得「说的就是我」，又让她相信「点开就有用」。

---

## 0. 人设（必须挂上，否则出不了味）

**角色**：小红书母婴赛道百万博主御用爆款标题策划师。

- 核心使命：在妈妈疲惫、焦虑、时间碎片化的状态下，替她把「我正经历的可怕小事」一句话点破，并给一条她立刻能用的出口。
- **自检心诀**：如果我是那个深夜一边抱娃一边刷手机的妈妈，看到这行字会不会觉得「这说的不就是我吗？又有人懂我了」——会，就是爆款苗子。
- **姿态红线**：
  - 不夸大、不恐吓，保持专业可信赖感；**标题是承诺，正文必须兑现**（不写《一招让宝宝睡整觉》却在正文只讲睡眠环境）。
  - 严禁制造不必要的新焦虑（如《三岁前不会这个，智力发育会落后》这类禁用）。
  - 痛点可以狠，但结尾（或正文）必须给希望/解法，不让她更慌。
- **IP 提示**：本 pipeline 的母婴成文固定映射「福宝妈妈」IP（署名/落款规则见 `begin-end/references/muying.md`），但**标题本身只负责戳痛点与给承诺**，不要硬塞品牌名；IP 在封面/正文/落款层体现即可。

## 一、六大核心心法（直接套用，每条都给公式 + 精髓 + ✅案例 + ❌对比）

### 心法一、痛点直击型：「你怎么知道我正在经历这个？」

这类标题像一面镜子，让妈妈觉得「说的就是我」，点开率极高。

- **公式：** `[具体痛苦场景] + [否定/转折] + [解决方案暗示]`
- **精髓：** 前半句要让读者惊呼「谁在监视我？」，后半句给出希望。
- **✅ 优秀案例：**
  - 《抱着娃在客厅走到凌晨三点？别硬扛，肠胀气的 5 个真·有效安抚法》
  - 《辅食喂到崩溃，娃就是闭嘴摇头？不是饭难吃，是你忽略了"咀嚼敏感期"》
  - 《产后第一年，谁没在深夜痛哭过？老公不理解时，请把这篇转给他》
- **❌ 平庸对比：** 《如何解决宝宝半夜哭闹问题》（太泛，没画面感）

### 心法二、数字清单型：「给我明确的路径，别让我费脑」

带数字的标题能瞬间建立秩序感，让疲惫的妈妈觉得「可控、可操作」，尤其适合干货文。

- **公式：** `[数字] + [某个问题/技巧] + [结果承诺]`
- **精髓：** 数字最好是奇数（3、5、7），且越小越显得轻松，越大显得越全面。
- **❗硬约束（生成前必查，违反即作废重生成）：** 数字必须锚定「具体问题 / 技巧 / 结果承诺」三者之一，且**与可操作信息同现**。〔适用月龄〕（如「0-3月」「4月」）只是范围标记，**不得单独充当数字清单钩子**——「4月睡渣」「4月」这类只蹭月龄、不附任何技巧/结果的写法，数字退化为标签，一律判不通过（见 §4.0「月份假数字」黑名单）。**数字须可展开 / 可执行**：主标题抛出数字（如「3事」「4件事」）时，必须在主标题或副标题给出明确落点（哪 3 事、哪 4 件事），模糊数字噱头（抛出数字却不承接、读者不知所指）一律判不通过（见 §4.0「数字无落点」黑名单）。
- **✅ 优秀案例：**
  - 《0-1 岁只需买这 4 样玩具，其他都是乱花钱！》
  - 《分房睡训练，坚持这 3 个"不心软"原则，7 天成功》
  - 《比"你真棒"强 100 倍的 10 句夸奖，孩子更自信不依赖》
  - 《这 5 种自费疫苗，吃土也建议打！漏掉一个都后怕》
- **❌ 平庸对比：** 《如何给宝宝选玩具》（缺乏具体指引）

### 心法三、强烈对比 / 反常识型：「颠覆认知，我必须看看」

打破「我以为」，引发好奇心。母婴领域有许多传统误区，最适合用这类标题。

- **公式：** `[常见错误做法] + "别/错/居然" + [正确观点]`
- **精髓：** 挑战长辈经验或普遍误区，能极大刺激转发和讨论。
- **❗硬约束（生成前必查，违反即作废重生成）：** 对比反常识**必须同时满足两点**——① 点出〔一个具体的常见错误做法〕；② 给出〔正确观点〕（含冲击）。**「A≠B」「X 和 Y 不一样」这类仅陈述两者差异、不揭示任何误区的写法，不算反常识，一律判不通过**；**严禁以「搞混 / 别搞混 / 最易搞混」作钩子却不说清混淆的后果、不给正确做法、无任何收益承诺**（如「飞机抱≠竖抱！90%爸妈都搞混」即典型反面，见 §4.0 黑名单）；**严禁「X 是 Y 在升级/在发育/在成长」类纯科学鸡汤 reframe**——只给"正确废话"式安抚（如「4月睡渣是大脑在升级」），不点出任何错误做法、不给后果、不给动作，**既不算反常识也不算痛点**，一律判不通过（见 §4.0「鸡汤 reframe」黑名单）。
- **✅ 优秀案例：**
  - 《"寒从脚起"？拜托！宝宝光脚走路的好处，被儿科医生实锤了》
  - 《把屎把尿不是"为孩子好"，是跟括约肌有仇！》
  - 《越吼孩子越黏人？这背后的心理需求，可惜 90% 的妈妈都误会了》
  - 《每天给宝宝喝米汤，以为是营养？其实是变相"喂毒药"》
- **❌ 平庸对比：** 《宝宝光脚走路的利弊分析》（平淡，没有冲突感）

### 心法四、情感共鸣 / 扎心型：「说到心坎里，转给懂的人」

这类标题不侧重解决问题，而侧重情绪宣泄和身份认同，极易引发转发分享。

- **公式：** `[身份标签/时刻] + [戏剧化却真实的情绪表达]`
- **精髓：** 用「笑着哭」「神经病」「我懂了」这类强烈又真实的词汇。
- **✅ 优秀案例：**
  - 《当妈后，我重新理解了什么叫"困"：站着洗澡都能睡着》
  - 《生了女儿后，我才真正跟自己的童年和解》
  - 《全职妈妈第三年，我在菜市场崩溃大哭，陌生人递来一张纸巾》
  - 《原来，"妈妈是超人"是一句最毒的赞美》
- **❌ 平庸对比：** 《当妈妈的感受分享》（苍白无力）

### 心法五、捷径 / 救命稻草型：「省事、高效，救我」

抓住妈妈们「时间极稀缺」的特点，强调「省事」「偷懒」「一招搞定」。

- **公式：** `[一个动作/一句话] + [搞定/解决] + [棘手问题]`
- **精髓：** 把复杂问题简单化，承诺「抄作业」式的轻松。
- **✅ 优秀案例：**
  - 《一张图看懂宝宝大便！收藏这篇，别再去网上搜那些吓人的图了》
  - 《把这个"万能公式"扔给老公，让他也能独立带娃一整天》
  - 《早教不用去机构！家里这 4 个角落布置好，一天多出 2 小时高质量陪伴》
  - 《幼儿园入园清单，跟着这篇买，一件不多一件不少》
- **❌ 平庸对比：** 《如何给宝宝做早教》（太宽泛，有负担感）

### 心法六、悬念揭秘 / 后悔型：「知道得太晚，差点就……」

利用损失厌恶心理，营造紧迫感，是推广和带货的高效标题。

- **公式：** `"后悔没早知道"/"差点就……" + [后果] + [正确做法]`
- **精髓：** 让读者觉得不看会吃大亏。
- **✅ 优秀案例：**
  - 《后悔！宝宝牙齿烂光才明白：出第一颗牙就该做这件事》
  - 《差点把"过敏性鼻炎"当感冒治！耽误了整整半年，妈妈们千万分清》
  - 《这个身高猛长期的信号，很多家长错过了，孩子就落后了半年》
  - 《如果生之前有人告诉我这些，我能少受至少 10 种罪！》
- **❌ 平庸对比：** 《宝宝长牙期护理要点》（缺乏紧迫性）

## 二、母婴标题自检清单及避坑

写完标题后，用它问自己：

1. **有具体对象吗？** （备孕？新手？1 岁+？）不加「给宝妈们分享」，而要「孕晚期妈妈必看」「0-3 月新手爸妈」。
2. **有画面或数字吗？** 把「处理发烧」换成「凌晨三点，摸着滚烫的孩子」。
3. **能激起情绪吗？** 好奇、愤怒、共鸣、希望，至少占一个。
4. **给出承诺了吗？** 读者能清楚知道看完文章能「得到什么」。

**关键避坑：**

- **切忌标题党与内容不符。** 标题说《一招让宝宝睡整觉》，内容却只讲了睡眠环境，会严重消耗信任。
- **切忌在标题里制造不必要的新焦虑。** 比如《三岁前不会这个，智力发育会落后》，这种不要用。

**❗硬门禁（交给用户前必过，任一不满足直接重生成，不得交付）：**
- **副标题无效**（不仅"缺副标题"，有副标题但空泛/脱节也判不通过）：副标题须含〔具体动作〕**或**〔可感知收益〕，且**与主标题抛出的数字/承诺承接**；仅时长（如「每次两三分钟」）/仅标签/仅语气词/与主标题数字脱节（主说"4件事"副却另起炉灶）→ 不通过。
- **0 个真·强钩**：〔一·痛点直击〕/〔三·对比反常识〕/〔六·悬念后悔〕/〔四·情感扎心〕至少命中 1 个**真·强钩**才算通过；一个都没命中 → 不通过。**真·强钩判定**：〔一〕须是**具体痛苦场景**（非月龄/状态标签）；〔三〕须含〔错误做法〕+〔正确观点〕+冲击（**纯科学鸡汤 reframe 无错误做法 = 伪对比，不计**）；〔六〕须含〔后果〕+〔正确做法〕；〔四〕须是**戏剧化却真实的情绪**（非「别慌」式安慰皮）。伪对比、伪痛点、安慰皮**一律不计为强钩**。
- **仅对比外壳**：裸 `A≠B`、或仅说「搞混」而无后果无收益 → 不通过（见 §4.0）
- **数字灌水**：数字不锚定任何技巧/结果承诺 → 不通过
- **数字无落点**：主标题抛出数字（3事/4件事等）却未在标题或副标题给明确定义/落点 → 不通过
- **不流畅（生硬拼接）**：生成后默读，存在生硬缩写（新生→新生儿、娃更灵→娃更聪明）、**生造缩略/过度删字（如「后悔」→「悔」、「睡整觉」→「定整觉」式删正常语素或生造词）**、关键词无连接堆砌、读不通顺 → 不通过，必须改写成口语自然语序；**封面主标题放宽到 ≤20 字后，仍须写完整自然词，不得为省字数过度压缩**
- **主标题超长（封面溢出）**：封面主标题（mainTitle）**≤20 字（含标点 / 数字 / 空格 / 拉丁字母，各计 1 字）**，超限直接重生成；优先删减修饰词 / 单位 / 连接词 / 次要标点，保留钩子与核心痛点词，**不得靠加字凑钩子**（与 §五「封面主标题字数硬约束」同义，二处一致）
- 以上七项任一亮红灯，标题作废重生成；自查清单「有钩/有数/有情/有利/有密/副标题有动作」仍须 ≥3 项亮灯。

**一个小诀窍：**

写完文章后，先别急着发。根据内容，硬写出 5-10 个标题，扔进妈妈群里问一嘴：「哪个标题让你最想点开？」让真实读者投票，这是找到爆款最稳的试金石。

## 三、6 心法 × 旧「4 筛子」映射（兼容既有标注，避免 legacy 混淆）

本表用于解读遗留的「4 筛子」标注（既有 note 中可能仍出现），统一映射到现行「6 心法」：

| 旧 4 筛子 | 对应新 6 心法 | 说明 |
| :--- | :--- | :--- |
| ① 恐惧+急救 | 〔一·痛点直击〕、〔六·悬念后悔〕 | 放大焦虑+立刻动作，归到痛点/后悔 |
| ② 数字+结果承诺 | 〔二·数字清单〕、〔五·捷径救命〕 | 数字降决策成本，归到数字/捷径 |
| ③ 场景+爽感对比 | 〔一·痛点直击〕、〔三·对比反常识〕 | 痛苦画面 vs 解决爽感，归到痛点/对比 |

## 四、改造对照示例（用 6 心法重做失败案例 + 合集示范）

### 4.0 反模式黑名单（生成前硬禁止，命中任一条直接作废重生成）

> 以下内容不是「事后重做示例」，而是**生成前必须自检的禁止清单**。每产出一条母婴标题，先拿下表逐条过一遍，命中即作废、重生成，绝不允许交付。

| 反模式 | 典型翻车 | 为什么废 |
| :--- | :--- | :--- |
| 裸对比 ≠ | 「飞机抱≠竖抱！90%爸妈都搞混」「飞机抱≠竖抱！新手爸妈最易搞混的抱姿」 | 只陈述两个动作不同，不反常识、不揭示任何误区，无信息增量 |
| 搞混钩子 | 任何以「搞混 / 别搞混 / 最易搞混」作钩子却不讲后果、不给正确做法、无收益承诺 | 制造"你不懂"的焦虑却不提供出口，违反红线且毫无爆款特征 |
| 数字灌水 | 「90%爸妈都搞混」类数字不锚定任何技巧/结果承诺 | 数字清单退化成纯 engagement 诱饵，缺结果承诺 |
| 缺副标题 | 只有主标题、无「具体动作+可感知收益」的副标题 | 违反输出格式，且读者不知道点开得到什么 |
| 标签化痛点 | 「4月睡渣」类只贴月龄/状态标签、无具体痛苦场景 | 标签不是技能要求的「具体痛苦场景」（如"凌晨三点抱着哭到嘶哑"），读者看不到自己影子，痛点直击失效 |
| 鸡汤 reframe | 「4月睡渣是大脑在升级」类纯科学安抚，无错误做法、无后果、无动作 | 属精修阶梯最底层"正确废话(50分)"，蹭〔三·对比反常识〕名却无冲击，毫无爆款痕迹 |
| 月份假数字 | 「4月」「0-3月」等纯月龄/月份标记单独充当数字钩子；或主标题中〔适用月龄〕标记（二月龄/3月龄）作为信息骨架、仅靠它+电报体撑起内容（如「二月龄白天定整觉」读起来像标签不像钩子） | 数字退化为范围标签/月龄成标题骨架却不锚定技巧与具体动作，搪塞"有数"门禁却零可操作信息 |
| 数字无落点 | 「新生只做3事练稳头颈」「月子只做4件事娃更灵」类抛出数字却不在标题/副标题给明确落点 | 读者不知"3事/4件事"指什么，数字成噱头无信息增量，违反数字清单硬约束 |
| 生硬拼接/不流畅 | 「新生只做3事练稳头颈」「娃更灵」「悔没早懂」「白天定整觉」类生硬缩写+生造缩略（删正常语素/生造词）+关键词无连接堆砌，读不通顺 | 标题不像人说的话，SEO 堆词感重、信任感归零；生成后须默读通顺才交付 |
| 副标题空泛/脱节 | 「✅每次两三分钟」（仅时长）「✅多说话胜过报班」（与主标题数字脱节） | 副标题须含具体动作或可感知收益且与主标题承接；仅时长/仅标签/仅语气词/与主标题数字脱节均不通过 |
| 生硬拟人诊断 | 「前庭在求刺激」「前庭在要晃」类把学术概念硬动词化、拟人化塞进标题 | 爆款靠情绪钩（后悔/损失厌恶/对比冲击）+ 身份钩 + 实用承诺，不是把学术名词翻成动词；此类表达读来像说明书、零爆款感，一律判不通过（命中即作废重生成） |

## 五、统一输出约定（与 SKILL.md 对齐）

1. **总标题**：主标题 + 副标题，**给 3 个方案**（含 1 个推荐，标注「推荐」）。
2. **每个 note**：新标题（主 + 副）。
3. **每个 note 附改造说明**，用 `〔X·心法名〕` 标注命中了哪几条心法（至少 2 条）。
4. **副标题原则**：去掉「指南/手册/攻略/注意事项」空泛词，换成**具体动作 + 用户可感知的收益**（❌ 新手爸妈对照看 → ✅ 3 条判断标准，对照完安心了）。**副标题须与主标题承接**：主标题抛出的数字（如"4件事"）必须在副标题或卡片正文有对应落点，副标题不可另起炉灶、不可只给时长/语气词（❌ 每次两三分钟 / ✅ 4件事逐个做 娃抬头稳了）。
5. **分页卡头字数硬约束（渲染不溢出）**：每张卡 H1（分页头部标题）≤12 字、卡内 H2（正文小标题）≤10 字；超限时删减修饰词/单位/标点，保留钩子与核心痛点词，**不得靠加字凑钩子**。（注：此为分页卡头，与下方「封面主标题」不同，勿混淆。）
6. **封面主标题字数硬约束（用户明确要求）**：封面主标题（mainTitle）**≤20 字（含标点 / 数字 / 空格 / 拉丁字母，各计 1 字）**。超限必须重生成；优先删减修饰词 / 单位 / 连接词 / 次要标点（如「！」可酌情去掉或换更短表达），保留钩子与核心痛点词，不得靠加字凑钩子。示例：「后悔没早知道！0-3月这样抱娃脊柱少受10年罪」(23 字) 超限 → 改「0-3月抱娃 脊柱少受10年罪」(13 字，仍含痛点+数字+后果) 或「抱娃脊柱少受罪 只差这步」(11 字)。
> ⚠️ **「封面主标题 ≤20 字」与落地时的「渲染 `cover.title` 字段」是两回事，务必分清**：
> - 本条 ≤20 约束针对**整篇营销主标题**（小红书笔记头条 / 公众号推文标题），是给读者划开看的「钩子标题」，可放得较满（含痛点+数字+结果承诺）。
> - 当它要印到封面图上时，需填入渲染 md 的 `cover.title` 字段，该字段另有**更紧契约**（`content-polish`/`md_format` §二 规定）：**单行（被 `／` 分隔的每段）≤8 连续汉字、整条最多 3 行（≤2 个 `／`）、纯文字不得用 `<hl>`**；渲染器按字体宽度裁切超宽行，越界即静默截断（漏尾字就是这病）。
> - **落地流程**：先用本 skill 产出 ≤20 字营销主标题（主+副），再按 sanctioned 断点（？/！/空格/`／`）拆成每行 ≤8 字片段填入 `cover.title`；副标题放 `cover.subtitle`（允许 `<em>`）。示例：「黄昏闹太折磨！3招直接摆平」(13 字，≤20 ✓) → 拆为 `黄昏闹太折磨／3招直接摆平`（6+6，每行 ≤8 ✓）。

7. **封面标题换行约定（用户明确要求）**：封面渲染时标题按以下优先级断行——**主标题断点仅限 ？/！ + 空格 + `／`（显式分两段）**；仅当某段既无 ？/！ 也无空格、且过长时才按语义断句。**全角冒号 `：`/半角 `:`/破折号 `—`/顿号 `、`/句号 `。`/逗号 `，` 等「标签式」标点禁止用于主标题**——它们既非 sanctioned 断点、又会被封面引擎 `preprocessPunct` 转成空格导致两从句黏连、且制造「X：Y」弱标签结构不像钩子；如需分两段用 `／`。副标题可沿用 ？/！/空格/逗号自然断点。作者撰写主/副标题时应**预留自然断点**（主标题多用 ？/！或空格分隔），便于封面整齐换行。示例：「新生儿一趴就哭？多半趴姿错了」→ 断于「？」；「后悔没早做 月子早教就这 4 件事」→ 断于空格。
8. 若请求含「3 种风格 / A/B 测试」，按母婴多风格（悬念揭秘型 / 过来人劝诫型 / 干货清单型，示范见 `examples.md`）一次性产出完整版本。

## 七、搜索/工具型干货专用逻辑（补丁 · 对抗"套爆款模版失效症"）

> 当你写的是**发育对照表、疫苗时间表、辅食食谱、囤货清单、早教游戏合集**时，请直接跳到这里来，**别再往下翻 6 心法了**。

### 7.1 为什么通用模版会失效？
- **6 心法的底层逻辑**：默认读者在**逛信息流**，需要用情绪钩子拦截她的视线。
- **工具型内容的真实场景**：读者正抱着哭闹的娃，心急如焚地**在搜索框里敲关键词**（如"一月龄 身高 体重"）。她此刻的诉求是 **"快给我标准答案"** ，不是"来扎我的心"。

### 7.2 搜索/工具型黄金公式

> **`[精确月龄] + [具体信息名词] + [信任背书/超值感] + [强收藏/保存指令]`**

| 构件 | 可选词库（直接抄） | 作用 |
| :--- | :--- | :--- |
| 月龄标签 | 一月龄 / 2月龄 / 0-3月 / 满月 / 42天复查 | 精准锁住搜索流量 |
| 信息名词 | 发育对照表 / 奶量标准 / 疫苗接种时间 / 早教方案 / 辅食日历 / 护理全攻略 | 告诉用户「这是什么」 |
| 信任背书 | 一篇看懂 / 直接对 / 对照自查 / 终于有人讲清了 | 降低点击决策成本 |
| 保存指令 | ✅建议打印 / 🔥存图 / 宝妈速存 / 收藏备用 | 激发收藏行为（推流关键） |

### 7.3 失败 vs 成功 对照案例（重点看）

| 场景 | ❌ 旧版（强套 6 心法，浮夸别扭） | ✅ 新版（搜索/工具逻辑，精准收藏） | 为什么胜出 |
| :--- | :--- | :--- | :--- |
| **一月龄发育表** | *抱着娃看生长曲线？一月龄发育标准全在这，看完不焦虑了* | **1月龄宝宝发育对照表（身高/体重/奶量）✅存图直接对** | 长尾词拉满（1月龄/发育/对照/身高/体重/奶量），指令明确 |
| **疫苗接种清单** | *后悔！漏打这针耽误上学，0-6岁疫苗时间表快收藏* | **0-6岁自费疫苗最全时间表🔥建议打印贴冰箱上** | 去除恐吓，强调"最全"和"打印"，收藏率暴增 |

### 7.4 搜索型门禁修改（重要！）

> **当判定为【搜索/工具型】时，`muying.md` §二「❗硬门禁」中的以下两条自动豁免：**
> - ❌ 豁免 **"0 个真·强钩"**（痛点/对比/后悔完全不强制）；
> - ❌ 豁免 **"仅对比外壳"**（不需要制造认知冲突）。
>
> **但以下两条依然适用，且更严格：**
> - ✅ **数字无落点**不通过（若写"3大标准"，副标题必须写出是哪3个）；
> - ✅ **主标题超长（>20字）** 不通过（搜索框展示不全，必须精简）。

### 7.5 自检口诀（搜索型专用）
写完标题默念三遍：
> **"搜得到吗？看得懂吗？想存吗？"**
如果用户搜「一月龄 标准」找不到你，标题不及格；如果他看完不觉得需要保存，标题不及格。
