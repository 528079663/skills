# 双版 / 多版模式（按平台调性）

> 本文件从原 writing-persona SKILL.md 外移而来，是「功能三：基于人设创作」的双版纪律权威来源。

当用户要求"出双版 / 公众号+小红书 / 按平台各来一篇"时，基于**同一话题 + 同一人设**，产出**两个（或多个）平台适配版本**。两版共享人设的「声音与价值观」（温柔坚定、不恐吓、循证、反焦虑），但**包装形态必须不同**。

## 平台调性预设

| 维度 | 微信公众号体 | 小红书体 |
|------|------|------|
| 标题 | 陈述式 / 设问式（如"宝宝有这8种表现，说明被你养的超好"） | 吸睛式（emoji+数字+痛点/反差，如"🌟养得好的宝宝有这8个信号！第5个太戳了"） |
| 结构 | 痛点引入 → 清单干货(N个X) → 逐条解读 → 支招框 → ps收尾 | 吸睛开场 → 极短段 + ✅/🔸清单 → 口语金句 → 文末话题标签 |
| 长度 | 清单型：每点 220~250 字，总字数随条目数浮动（≈N×240+开头结尾）；非清单单篇 800–1500 字 | 600–900 字，1–3 行内；单点压缩 90~180 字 |
| 语气 | 温柔坚定、娓娓道来、引证科学 | 更闺蜜、更"姐妹听我说"、情绪更外放 |
| 格式 | 纯文字为主，少量 emoji，支招框用「福宝妈说：」等文字标记 | emoji 密集、换行多、关键词前加符号、结尾带 #话题 |
| 标志话术 | 点到 1–2 处 | 可更活泼地化用，但仍不照搬 samples |

## 双版硬规则（9 条）

1. **同核不同壳**：两版核心观点/知识点一致，但标题、开头钩子、段落节奏、emoji 密度、结尾明显不同，禁止"同一篇换个标题"的伪双版。
2. **防套路对两版分别生效**：每一版都独立满足「samples 不复制 / 三新 / 支招框适度 / 标志话术点缀」，不得因出双版就放松任一条。
3. **人设一致性**：两版都要保留该人设的价值观与避雷（如仍不恐吓、仍反焦虑），只是表达轻重不同。
4. **交付**：两个版本分别成稿，并各附一句"本次如何避免套路"；若用户指定平台则只出对应版。
5. **禁止 AI 模板化元标签**：小红书体（及任何版本）**不得出现**「金句收尾💛：」「底层逻辑💡：」「冷知识🧊：」这类"名词+emoji+冒号"的元标签——真人博主不会在正文写"金句收尾"四个字。要像真人自然分享：知识点直接说（如"划个重点："、"说个冷知识："），收尾金句直接写、不加标签。emoji 仅用于情绪点缀（如😭🌟🌙），不与抽象名词拼成结构化标签。
6. **禁止中英混写残次词 / 机翻残留**：成稿**不得出现**「你-handed」「the-关键」「our-温度」这类英文单词错混进中文的残次品（本质是把"你把握的/我们的"等误拼成英文）。正常人看不懂，纯 AI 味。自检时逐句扫：凡出现孤立英文单词夹在中文句子里、且非专有名词/术语/品牌名，一律改写为纯中文。确需英文名（如婴儿抚触 touch、袋鼠式护理 kangaroo care）应整词保留并加中文注释，不半中半英。
7. **分点论述每点 220~250 字（清单型，统一上限）**：凡**分点论述**（含「N 个 X」式清单文章的各要点，以及非清单但分条展开的文章），每个要点条目的正文展开（含原理+做法+好处，**不含**编号/标题）以 **220~250 字**为目标。其中**清单型文章**允许 **220~250 字**弹性区间（中心约 235），各点详略一致、不忽长忽短。此约束适用于**图文文章（公众号体等逐条详述型）**，且**优先级高于总字数区间**——总字数由「单点×条目数 + 开头结尾」自然决定（如 8 点文章总字数约 1600~2240 字属正常）。小红书体整体 600~900 字、单点压缩至 90~180 字；若用户明确要求小红书也逐条长展开，则按单点 250 字执行、总字数相应上浮。
   - 注：本标准的「字」指**汉字字符数**（不含标点、空格、英文、emoji、#话题标签）。若将来改为「含标点的总字符数」，各区间需相应上浮约 10%~15%（如单点 220~250 → 约 242~288）。以用户当时确认为准。
8. **标题由标题 skill 拟定（禁止手写）**：图文文章标题由 `meta-topic-plan` skill 拟定（公众号 ≤28 字（与 meta-topic-plan 平台约束一致）、≥4 套不同公式，覆盖数字清单 / 避坑警告 / 自问自答 / 反常识 / 时效紧迫等类型），不手写套模板；图片贴图封面主/副标题由 `xhs-title-factory` 拟定（见防套路硬规则 8）。两 skill 均属"标题生成"权威来源，禁止凭印象手搓标题或沿用旧标题公式。

9. **文章可读性：善用断句、小标题、换行，禁止长篇累牍**：图文文章（公众号体等）成稿**不得出现大段密集文字墙**——凡连续正文超过约 4–5 行（≈120–150 字未分段），须**主动断句换行或用小标题切分**：① 长论述拆成「小标题 + 短段」层级（如「❌ 误区」「✅ 正确做法」），结构一眼可见；② 一段内用换行把关联短句在视觉上分开、制造停顿；③ 关键转折/并列用短句成行。目标「读着不累、扫读能抓重点」，**切忌从头到尾不分段的密铺文字**。**本规则在文章转换（产出图文文章）时重点把控**；小红书体本就靠短段+换行节奏，沿用即可。

## 执行

1. 确认本次话题与所需平台组合（默认：公众号体 + 小红书体）。
2. 先按单版规则、并**套用 writing_craft 的 structure_template / signature_boxes / title_formulas** 起草**公众号体**（主版本，信息最完整、最贴近原作者骨架）。
3. 再基于同一核心，改写为**小红书体**（压缩、加 emoji、改标题、补话题标签），不得直接复制公众号体文本。
4. 两份分别自检防套路规则后交付。
5. **分文件存储**：双版/多版文案**不合并在一个文件**，每个平台版本独立保存为单独文件，文件名加平台后缀（如 `话题-公众号体.md` / `话题-小红书体.md`），便于用户按平台取用。
