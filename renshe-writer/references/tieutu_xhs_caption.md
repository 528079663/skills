# 贴图小红书文案（caption）规范

> **来源与定位**：本规范由 `tuwen-md-convert`（原小红书出图 skill，其渲染后端已废弃）沉淀而来——该 skill 的「小红书文案公式」是其唯一被 route A 复用的部分。route A 中，贴图小红书文案（caption）作为 **③ 人设创作的前移产出**，与本 skill（renshe-writer）的图片贴图文案稿 `0_tieutu_<主题>.md` 配套交付，是发笔记时的「标题 + 正文 + 话题标签」纯文本配文。
>
> ⚠️ **与文章双版区分**：本规范 ≠ renshe-writer 文章的「小红书体」（文章双版，600–900 字整篇）。两者同名但不同物——文章小红书体走 `writing_rules_dual_version.md`，本 caption 只针对**贴图发帖**，200–400 字纯文本。

## 黄金公式：身份 + 痛点 + 情绪 + 结构

以**第一人称"我"**口吻，先立人设，再戳痛点，再给结构化解法，最后情绪升华 + 引导互动。

### 结构（必含 4 段）

1. **标题（钩子）**：争议 / 反直觉型，**≤20 字**；给 1 个主标题（如「千万别瞎等！新生儿疫苗这坑我替你踩过」）。禁用平铺陈述。
2. **开头（0–3 行）**：感叹句直击目标用户痛点，制造焦虑或共鸣（如"谁懂啊！第一次抱娃去打疫苗对着接种本直接发懵😵"）。
3. **正文（痛点+解法）**：分 **3 点**，每点固定结构 = **「emoji + 冒号标题 + 一句话大白话」**（如 `💉 免费≠不重要：一类免费二类自费，区别只在付费途径，不是重要性！`）。**整篇为纯文本，禁用任何 markdown 语法**——见下方「纯文本（强约束）」。
4. **结尾（情绪升华+互动）**：一句走心金句总结 + **开放式互动引导**（用自然提问或分享邀约引导评论，如"你家娃最让你抓瞎的是哪个信号？评论区聊聊"，**不再强制 A/B 选择题**）+ 引导点赞/收藏。

### 文风与避坑（强约束）

- 多用感叹号、波浪号（~）、口语词（绝了/谁懂啊/真的顶不住/按头安利）；正文建议含 **≥3 个 emoji 分点**（与下方文案验证脚本阈值一致）。
- **禁用词**：「众所周知」「综上所述」「堪称完美」「非常漂亮」——改成「把我拿捏住了」「美到失语」等真人感表达。
- **去 AI 味**：用"说实话/有一说一/划重点"替代"首先/其次/总之"；加 1–2 个口头禅（咱就是说/真的会谢）。
- **换行**：每 2 行必须空一行，否则密密麻麻没人看。
- **纯文本（强约束）**：文案给人直接复制到小红书发布框，**禁用任何 markdown 语法**——不要 `# 标题`、`## 小标题`、`**加粗**`、`*斜体*`、`- 列表` 等符号（小红书发布框不渲染 markdown，会原样显示成乱码）。分点用 `emoji + 冒号` 即可（如 `💉 免费≠不重要：…`）；话题标签保留平台原生写法 `#话题`（这是小红书话题格式，不是 markdown，必须保留）。
- **字数**：正文（标题与 `#标签` 不计入）严格 **200–400 字**，超出或不足都打回重写。此处「字」= **非空白字符总数（含标点、emoji、英文、数字）**，由 `validate_xhs_caption.py` 实测统计；与图文文章/图片贴图「汉字不含标点」口径**不同**，不要套用后者标准。
- **人设映射**：母婴赛道固定 = **福宝妈妈**（自称"我"，宝宝名"福宝"正文低频出现）；其他赛道按用户指定身份。**小红书文案不需落款**：账号昵称已展示作者身份，正文与话题标签均不加署名（不要「——福宝妈妈说」这类署名行，也不要 `#福宝妈妈说` 这类署名标签）。
- **话题标签**：文末 **3–6 个 `#标签`**，母婴选含赛道主标签 + 相关话题（不加 `#福宝妈妈说` 署名标签）；标签不算入正文字数。

### 输出格式

写进 `03_创作/0_tieutu_<主题>_小红书文案.md`（与 `0_tieutu_<主题>.md` 同目录、同名前缀），三段式（标题 / 正文 / 标签）：

```text
标题（钩子，≤20字，纯文本，不要 # 号）

（空行）
正文……每2行空一行，分点用 emoji+冒号，无加粗无标题符号……
（空行）
#新生儿疫苗 #新手爸妈 #育儿干货 #疫苗接种 #宝宝健康
```

### 文案验证脚本

写完跑 `scripts/validate_xhs_caption.py <文件>` 确认字数/结构达标，不达标就重写：

- 正文字数 200–400（标题与 `#标签` 不计入）
- 无 markdown 语法（`**`、`# 标题` 等）
- emoji 分点 ≥3
- 结尾有开放式互动引导（评论区/聊聊/说说/留言等）

> 文案由 agent 按公式**现写**（需 LLM 创造力，无自动生成）；脚本只做字数/结构的程序化校验。卡片病毒性靠 `xhs-title-factory`，文案病毒性靠本公式。
