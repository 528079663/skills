# 防套路硬规则（每次创作前自查）

> 本文件从原 writing-persona SKILL.md 外移而来，是「功能三：基于人设创作」的防套路纪律权威来源。renshe-writer 的 SKILL.md 仅引用本文件，不在主文档内联大段规则。

## 人设的两层定位（必读）

- **风格层（应复用）**：profile 中的 tone / voice / 句式习惯 / 词表 / 价值观 / 避雷。定义"怎么写"，每次创作都应遵守。
- **骨架层（应复用）**：`profile.content_modes[<内容类型>].writing_craft`（兼容回退到顶层 `profile.writing_craft`）中的 structure_template / signature_boxes / title_formulas / layout / paragraph_rhythm / argumentation / length_profile。"文章怎么搭"的模板与排版签名，每次创作都应遵循。复用骨架 ≠ 复制句子。
  - **内容类型路由**：先确定产出「图文文章」还是「图片贴图」，取对应模式的 writing_craft；两者结构不同，不可混用。
- **内容层（禁止照搬）**：`samples`、`signature_expressions`、`writing_craft.examples` 里的示范片段，只用于体会腔调与框形态，绝不允许原样复制。

## 防套路硬规则（10 条）

1. **samples / 示范不复制**：绝不直接挪用 `profile.samples`、`signature_expressions` 或 `writing_craft.examples` 中的任何一句；它们是示范，不是素材库。但 writing_craft 的 structure_template / signature_boxes / title_formulas / layout 等"骨架与格式"可以且应当复用。
2. **三新原则**：每篇至少满足「新角度 / 新亲身 anecdote（编一个该人设下的、**承载新信息**的小故事，非旧例改名克隆）/ 新权威引用」中的两条，确保内容新鲜。**"新角度"合格标准（硬）**：必须改变文章的**内容组织轴**（即"按什么维度展开论点"），例如从"枚举6种X→Y"改为"按月龄 / 按场景 / 按性别 / 按睡眠质量"分维度，或换核心论点；仅替换案例人名、同义改写、换标题 = **不算**新角度。**同主题再创作时，"新角度"为强制项（必须换内容组织轴），其余两项至少再满足一项**——写前门禁见 SKILL.md「同主题再创作差异化门禁」。
3. **支招框按需不堆 + 逐点轮换**：`✅我这样做：` / `图X做法：` / `X-妙招👇` / `X说：` 等品牌框按话题轻重选用，不机械每篇摆满、不固定顺序；**同一篇图文文章内，相邻/多个要点不得复用同一支招框 opener 原文字符串**——从 persona `signature_boxes` 池（含 `👶心里话：` 共情框、专题框如 `福宝妈-安睡妙招👇`）与同族变体（`✅我是这么做的：` / `✅试试这个：` / `✅平时我会：` / `✅给你个实在招：`）中轮换，杜绝「✅我这样做：」五连发。**尤其禁止「我这样做！」在文中反复出现（用户硬性要求，二月龄大运动文章曾犯 opener 雷同已纠）**；表达重复约束扩展到全文：句式、近义词、同一动作也不得换种说法连写堆砌。
4. **开头不固化**：不一定都用"我家X…"起手，可按当次话题换钩子（痛点提问、数据反差、场景切入）。
5. **维护已写主题（工具落地，非会话记忆）**：同一人设下写过的 主题 / 角度 / 核心论点 **必须**用 `scripts/topic_log.py record` 登记到 `~/.workbuddy/personas/topic_log.json`，**禁止只靠会话记忆**（易丢、不可查、可被"改名换皮"糊弄）。同主题再创作前先 `topic_log.py check <persona_id> --topic <规范化主题>` 查已用角度，确保本次角度不同。写后务必 `record`。门禁流程见 SKILL.md「同主题再创作差异化门禁」。
6. **标志话术点缀即可**：`signature_expressions` 里的口头禅每篇点到 1–2 处即可，当"味儿"而非"骨架"，切忌每句都挂。
7. **密度不超源文（★成稿后必查，防密度漂移）**：人设专属指代（如自家娃小名「福宝」、自称）在成稿里的出现次数 / 分布，**不得超过**该人设 `content_modes[对应类型].frequency_notes` 记录的源文实测密度。若源文是「稀疏使用（1/5 篇）」，成稿的 5 点/5 卡里最多 1~2 处带娃案例，**绝不能每点/每卡都塞**。占位符 `{baby_name}` 等生成时才回填为人设品牌名，回填后仍受此密度约束。
8. **贴图封面主/副标题各 ≤15 字（主副各自独立计数）+ 副标题前固定 ✅**：图片贴图封面是艺术大字，**主标题与副标题各自单独 ≤15 字**（不是"标题+副标题合计15字"）。副标题文字前固定加 `✅`（通用要求，所有贴图均适用，与支招框『✅我这样做：』风格统一）。**封面主/副标题须由 `xhs-title-factory` skill 拟定（禁止手写）**，见下方内容类型小节。严禁把公众号长钩子原样搬来当封面标题。
9. **卡片规格 = 自然语言文案，禁字段标签外露 + 卡内可读性约束**：贴图模式的产出是「每张卡的自然语言文案」（每卡 = 标题 + 一段正文 + 一个 tip 框），**不是带字段标签的标注文档**。生成时不得输出 `## 【卡片N】`、`- **场景代入**：`、`- **原理**：` 这类结构标签——字段仅作内部组织思路，交付前必须翻译成连贯段落。**卡内可读性（与图文文章同精神，但受卡片容量约束）**：① 单卡正文（不含标题/tip 框）须受字数约束——**以该人设 `profile.content_modes["图片贴图"].writing_craft.length_profile.per_item_chars` 的实测值为准**（例如常见母婴人设约 220~250 字，不含标点）；仅当该字段缺失时才回退默认 ≤200 字。注意：贴图卡字数以人设实测为准，不等于"必须短于文章 250 字"，不得据此把卡写短；② 卡片正文善用断句 / 换行，不铺成长段落；多论点卡内用短句成行、扫读能抓重点，禁止长篇累牍。
10. **占位符/元指令禁入正文 + 话术不重复**：① 占位符注解（如 `（{baby_name}）`）与给校对员的元指令（如「人工核对提示」）**禁止写进最终文件**，仅在对话中口头说明；② 同一引导/支招句式不得原样重复——**图片贴图跨卡**不五卡复读（如「可以建议…」），**图文文章逐点**不重复同一支招框 opener（如「✅我这样做：」不五点连发）；每卡/每点 tip 换说法。

## 交付前全量自检清单（硬规则逐条勾选，缺一不可；任一项未过不得宣称"完成"）

> 生成后**必须重新读取实际产物文件**逐条核对，禁止仅凭记忆/对话总结宣称已通过。

1. 硬规则8：贴图封面主/副标题各 ≤15 字（主、副各自独立计数，非合计）；**副标题前固定 `✅`（通用要求）**；封面主/副标题**由 `xhs-title-factory` skill 拟定（非手写）**。
2. 硬规则9：卡片=自然语言文案；无 `## 【卡片N】`/`- **字段**：` 等标签外露。
3. 硬规则10：正文无 `{baby_name}/{brand_name}/{self_refer}` 字面量；无跨卡原样重复的句式。
4. 硬规则7：娃小名/自称出现次数与分布 ≤ `frequency_notes` 源文实测密度（稀疏标记不得每卡塞）。
5. **模式专属支招框**：图片贴图模式只用该模式高频标记（如「可以建议」），**禁止**把图文文章模式标记（如「福宝妈说」）搬进贴图；跨模式混用=不合格。
6. **无自加元素**：全文扫描 ❤️ / 💡 / ⚠️ / 收藏·关注 CTA / 独立结尾卡 / 人工核对提示，须为 0。
7. 禁 AI 模板化元标签：无「金句收尾💛：」「底层逻辑💡：」等"名词+emoji+冒号"标签。
8. voice/语气：保留第一人称共情、不恐吓、反焦虑；无复制 samples/示范句。
9. **可读性（两种模式重点把控）**：
   - **图文文章（文章转换重点）**：无 ≥4–5 行未分段的文字墙；长论述已用断句 / 小标题 / 换行切分，扫读能抓重点；分点论述每点 220~250 字（清单型）；**支招框 opener 已逐点轮换、无同一字符串多要点重复（硬规则3）**。
   - **图片贴图**：每张卡正文善用断句 / 换行、不堆成长段落；单卡正文（不含标题/tip）以该人设 `profile.content_modes["图片贴图"].writing_craft.length_profile.per_item_chars` 实测值为准（字段缺失才用 ≤200 默认）；保持短平快扫读节奏；无长篇累牍卡。
10. **同主题再创作重叠自检（硬）**：若本次为同主题再创作，须确认与上次产出的「内容组织轴 / 核心论点」**确实不同**——若仅案例人名 + 同义词不同、组织轴一致，判 **FAIL**，必须重选角度重写（门禁见 SKILL.md）。交付"本次如何避免套路"时，同主题情形须附「与上次角度差异」一句。
