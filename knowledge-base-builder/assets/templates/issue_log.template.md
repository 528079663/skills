## 历史记录

### #1 · ChangeExtension 自动补点号导致配对检测失效
- 日期：{{date}}
- 现象：扫描 184 个妙记 txt 的同名精华笔记，检测结果全部为"不存在"；但直接按文件名搜索可找到 185 个精华笔记。
- 根因：`[System.IO.Path]::ChangeExtension(path, '·精华笔记.md')` 的新扩展名参数不以 `.` 开头时，方法会自动在前面补 `.`，得到 `xxx.·精华笔记.md`，与实际文件 `xxx·精华笔记.md` 不符。
- 解法：改用字符串替换 `$path -replace '\.txt$','·精华笔记.md'` 构造候选路径。
- 预防：.NET 路径 API 处理非常规扩展名时先验证输出字符串；配对检测统一用正则替换构造路径。
- 状态：已解决
- 影响范围：妙记精华覆盖率统计（修正后为 166/184 = 90.2%）。
