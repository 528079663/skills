## 4. 怎么用（常用入口）

| 想做什么 | 看哪里 |
|---|---|
| 按项目一键拉取知识 | `projects/<项目>/recipe.yaml`（跑检索脚本 `pull`） |
| 找某主题 / 关键词资料 | `00_导航/模块视图.md`、检索脚本 `search`，或 `00_导航/文件目录.md` |

| 记录项目进度 | `projects/<项目>/PROGRESS.md` |

| 检查更新 / 同步 | 按 AGENTS.md「变更同步」执行 |
