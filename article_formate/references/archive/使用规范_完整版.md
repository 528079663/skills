## 一、快速开始

```bash
# 进入 skill 目录
cd <SKILL_DIR>（article_formate skill 根目录）

# 运行转换器（草稿.md -> 输出.html）
python scripts/format_article.py 你的草稿.md -o 输出.html
```

生成后，把 `输出.html` 的**全部内容**复制，粘贴进公众号编辑器（或秀米/135 的「导入 HTML」）即可。

> 移动端预览建议：草稿每行控制在 35–40 字，便于手机阅读。

## 二、输入语法一览表（速查）

| # | 元素 | 草稿写法 | 渲染规则 |
|---|------|----------|----------|
| 1 | 文章大标题 | `# 标题` | 独占一行，`#` 后**必须一个空格**；居中加粗，20px |
| 2 | 小标题（蓝标） | `## 标题` | 浅蓝底+蓝顶边+蓝色粗字，宽度随字成标签，17px |
| 3 | 子标题 | `### 标题` | 蓝色竖条+蓝粗字，16px |
| 4 | 段落 | 普通文字 | 空行分段；段内换行保留为软换行 `<br>` |
| 5 | 加粗关键词 | `**词语**` | 朱红 `#D92142`；内容内**不能再出现 `*`** |
| 6 | 斜体 | `*文字*` | 轻微强调；内容内**不能再出现 `*`** |
| 7 | 行内代码 | `` `code` `` | 浅底小字；**不支持 ` ``` ` 围栏代码块** |
| 8 | 黄底高亮 | `==重点句==` | 亮黄底 `#FFFB00` + 深色字（你文章高频用法） |
| 9 | 引用 | `> 文字` | 每行以 `> ` 开头，多行合并为引用块 |
| 10 | 无序列表 | `- 项` | `-` 后**必须空格**；仅支持平铺 |
| 11 | 有序列表 | `1. 项` | 数字 + `.` + 空格；仅支持平铺 |
| 12 | 分割线 | `---` | 独占一行三个减号，细灰线 |
| 13 | 图片 | `![图注](URL)` | 独占一行；图注显示在图下（灰字）；URL 不能含 `)` |
| 14 | 提示框 | `::: tip` … `::: end` | 类型 `tip`/`warning`/`info`；结尾**必须 `::: end`** |
| 15 | 固定模块 | `{{header}}` `{{qr}}` 等 | 独占一行；需在 `theme.json` 开启 `modules`，否则静默丢弃 |

## 六、必须避开的 7 个坑（来自转换器真实逻辑）

1. **草稿里不要写 HTML 标签**：`<` `>` `&` 会被转义成纯文本显示。要特殊样式就改 `theme.json`，别在草稿里塞标签。
2. **不支持嵌套列表、不支持 ` ``` ` 围栏代码块**：列表只做平铺（缩进不会生成子列表）；三反引号会被当普通段落。
3. **标题 `#` 后必须一个空格**：`#标题`（无空格）不被识别，会成普通段落。
4. **引用 `>` 后必须一个空格**：`>文字`（无空格）不变引用块。
5. **占位符没开启 = 无输出（不报错）**：`{{qr}}` 等若 `theme.json` 的 `modules.xxx` 为 `false`，就什么都不生成。先开模块。
6. **加粗/斜体内部别含 `*`**：`**a*b**` 会匹配失败，多余单 `*` 还可能把别处文字误变斜体。
7. **图片整行必须严格是 `![...](...)`**：前后不能有其他字符；URL 一旦含 `)` 会被截断。

## 七、自定义：修改 theme.json

所有样式都由 `references/theme.json` 驱动。想微调风格（如蓝标圆角、正文行距、字号），直接改对应字段后重跑转换器即可：

```jsonc
"headings": {
  "h2": {
    "background": "rgba(81, 151, 248, 0.13)",  // 蓝标底色
    "border_top": "2px solid #2E81DA",          // 蓝标顶边
    "border_radius": "4px",                     // 改这里调圆角
    "display": "inline-block"                   // 标签式宽度自适应
  }
},
"emphasis": {
  "strong_color": "#D92142",   // 加粗色
  "mark_bg": "#FFFB00",        // 高亮底
  "mark_color": "#1a1a1a"      // 高亮字
}
```

> 修改后无需改脚本，重跑 `format_article.py` 即生效。
